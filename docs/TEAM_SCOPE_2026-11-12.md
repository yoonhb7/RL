# 2026-11-12 팀 실험 범위 결정

현재 연구는 **가상 연속 사거리 2개를 하나의 중앙 DQN이 제어**하는 PedLink-Corridor2다. 실제 세종대 앞 도로의 재현은 이번 범위에 포함하지 않는다.

교차로 수는 환경의 제어 지점 수이며 에이전트 수와 다르다. 두 사거리의 상태를 하나의 52차원 입력으로 모으고, 하나의 52→128→128→9 신경망이 두 곳의 공동 요청 조합을 선택한다. 독립 모델 2개 또는 멀티에이전트 학습을 사용하지 않는다.

- [45회 평가 요약](../experiments/pedlink-corridor2-dqn/results/comparison.csv)
- [검증 기록](../experiments/pedlink-corridor2-dqn/results/verification.json)

기존 보행자 우선 규칙과 대기 연동 전환 비용을 현재 사거리 환경에 이식하고 세 변형을 각각 30회 새로 학습했다. 고정 신호·대기열 규칙까지 포함한 45회 평가를 완료했다. 차량·보행자 전원 도착, 잔여·미진입 0, 충돌·teleport 0이었다.

한 번의 독립 학습과 합성 수요를 사용한 탐색 실험이다. 전환 비용의 일반적 우수성, 현실 도로 성능, PPO 대비 우수성은 아직 검증하지 않았다. 이전 횡단보도 4곳과 차량 전용 두 사거리 모델은 각 브랜치에서 보존한다.
