# 실제 실행 검증과 파일럿 결과

작성: 2026-11-13. 기준 논문은 Pálos & Huszák, SoftCOM 2020. 실제 SUMO 1.28.0으로 실행했다.

## 완료한 검증

- 분석/통합 검사 8개 통과: 6개 보상, Double 타깃, Dueling 결합, 4모델의 가중치 변경·체크포인트, 차량 파일 재현성, 실제 황색 3초, 미진입 집계, 학습→저장→재평가.
- 주 파일럿: 3알고리즘×3교통량, WTMin, 학습 시드11, 모델당 6에피소드. 9모델·총54에피소드 학습 완료.
- 모델마다 미사용 차량 시드1001/1002/1003으로 평가: 27회.
- fixed/queue 기준선: 2제어기×3교통량×차량시드3 = 18회. 주 보고서에 총45평가 포함.
- 보상별 별도 실행 확인: 중교통량 DQN, 6보상 각각 1에피소드 학습+1평가. 각 모델의 실제 gradient update와 파일 저장 확인. 이 수요/학습량은 주 파일럿과 달라 보고서를 합치지 않음.
- 코드 수정 후 작업표 재생성·새 출력 경로로 재실행. 이전 실패/시도는 기록으로 보존했으며 주 결과에 포함하지 않음.
- 재실행 시 9개 완료 작업을 모두 건너뛰는 것을 확인.
- 공유 ZIP을 다른 폴더에 풀어 doctor와 저교통량 고정 신호 평가를 재실행했다. 예정127대 전부 도착, 미진입0, 대기8.70초/예정차량으로 상대 경로 실행을 확인했다. 다른 하드웨어의 CUDA 실행은 검증하지 않았다.
- 실제 SUMO GUI로 학습된 high Double DQN을 끝까지 실행하고 180초 부근 화면 캡처. 표시: 차량 도형, 빨강/초록 정지선 신호, 청록 50m 검지영역. 호환성을 위해 단순 차량 도형 사용.

2026-11-14 도시형 표시 개선도 완료했다. 자동차·실제 신호와 연동한 3색 신호등·건물·공원을 추가했으며, 장식 유무에 따른 13개 교통 결과가 동일했다. 기존 파일럿 수치는 당시 코드 기록으로 유지한다. 상세 내용은 [도시형 화면 설명](CITY_VIEW_KO.md), 새 이미지는 [실제 SUMO 상태를 사용한 벡터 미리보기](results/city-live-view/high-demand-1001/simulation.png)를 참조한다. 새 이미지는 네이티브 GUI 픽셀 캡처가 아니다.

## 주 파일럿 결과

파일럿은 발생600초+정리180초, 수요450/1500/3000 veh/h다. 표의 대기는 `(관측 정지 차량·초+혼잡 미진입 차량·초)/예정 차량 수`를 평가 차량 시드3에 대해 평균한 값이다. 완료율과 대기열을 반드시 함께 읽는다.

| 평가 교통량 | 제어기 | 보정 대기(초/예정차량) | 완료율 | 평균 정지 대수 |
|---|---|---:|---:|---:|
| low | fixed | 8.25 | 100.0% | 0.83 |
| low | queue | 3.46 | 100.0% | 0.35 |
| low | dqn | 1.27 | 100.0% | 0.13 |
| low | double | 0.60 | 100.0% | 0.06 |
| low | dueling | 0.80 | 100.0% | 0.08 |
| medium | fixed | 9.57 | 100.0% | 3.17 |
| medium | queue | 4.13 | 100.0% | 1.37 |
| medium | dqn | 12.30 | 99.1% | 4.08 |
| medium | double | 27.12 | 93.8% | 9.00 |
| medium | dueling | 189.70 | 55.0% | 58.46 |
| high | fixed | 23.82 | 99.0% | 15.32 |
| high | queue | 25.62 | 92.9% | 16.21 |
| high | dqn | 234.57 | 49.3% | 82.92 |
| high | double | 241.56 | 48.3% | 84.41 |
| high | dueling | 241.56 | 48.3% | 84.41 |

**저교통량에서는 학습 효과가 나타났지만, 중·고교통량은 현재 짧은 파일럿에서 안정화되지 않았다. 특히 고교통량 학습 모델은 일부 방향을 장시간 방치해 고정 신호보다 나쁘다.** 이 결과를 숨기거나 알고리즘의 일반적 우열로 해석하지 않는다. 본 설정의 더 긴 학습과 독립 학습시드 반복이 필요하다. 보상6종×교통량3×알고리즘3의 최종 연구 결과는 아직 없다.

같은 평가 차량 시드로 fixed 기준선의 평균 대기열이 저·중·고로 증가한다. 고교통량은 정리시간 후에도 일부 차량이 남으므로 이 수요를 '모든 차량이 통과하는 정상 상태'로 가정하지 않는다.
