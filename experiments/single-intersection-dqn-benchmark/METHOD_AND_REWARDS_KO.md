# 구현 명세와 원문 재현 범위

기준: Pálos & Huszák (SoftCOM 2020), DOI [10.23919/SoftCOM50211.2020.9238290](https://doi.org/10.23919/SoftCOM50211.2020.9238290).

이 구현은 **논문을 참고한 통제 비교 환경**이다. 저자 원본 코드·네트워크 파일·모든 보상 수식을 확보한 수치 재현이라고 주장하지 않는다. 이전 IntelliLight 구현 검토는 중단됐으며 현재 학습 코드는 별도 신규 작성했다.

## 논문에서 유지한 요소

- SUMO 단일 사거리, 접근 방향당 유입 1차로, 직진·우회전.
- 접근 방향마다 검지영역 차량 수·점유율·평균속도, 현재 신호: 입력 13개.
- 행동 0=유지, 1=다음 신호로 전환. 녹색 1초 단위 판단, 황색 3초 동안 판단하지 않음.
- 512→256→64 ReLU 완전연결층과 He 초기화. 일반 출력 2개; Dueling은 V 1개, A 2개, `Q=V+A-mean(A)`.
- 주요 학습 설정: 학습률 0.0005, gamma 0.9, batch 32, replay 50,000, learning starts 1,000.
- 논문의 보상 6종을 모두 선택 가능. 주요 비교 3알고리즘과 선택 D3QN 구현.

## 이번 실험을 위해 명시적으로 정한 요소

| 요소 | 이번 구현 |
|---|---|
| 도로 길이 | N/E/S/W 300/350/400/450m. 통행 길이 가중 보상이 동일 대수 보상과 완전히 같아지는 것을 피하며 전 조건 고정 |
| 검지영역 | 정지선 앞 50m E2 detector. 차량 수 clip[0,10], 점유율/10, 속도/제한속도×10으로 0~10. 현재 현시 0/1 |
| 상태 전처리 | 모든 모델에서 동일하게 13개 입력을 10으로 나눔. 빈 검지영역 속도는 0 |
| 행동 | NS/EW 녹색을 번갈아 선택. 허용 우회전도 해당 접근방향 녹색에서 통행. 최소 녹색 1초, 별도 최대 녹색 제한 없음 |
| 황색 | 실제 SUMO yellow 사용. 황색 진입 가능 여부는 SUMO의 제동·통행 규칙 적용. 논문의 '모두 차단' 문장을 물리적으로 임의 강제하지 않음 |
| 차량 수요 | 매초 방향별 Bernoulli 발생을 경로 XML에 미리 기록. 우회전 20%, 방향비율 25%씩. 제어기의 난수나 막힌 삽입에 따라 발생 계획을 바꾸지 않음 |
| 원문 수요와 차이 | 원문 학습은 사인+무작위, 평가는 randomTrips. 이번 주 실험은 저·중·고 각각 독립 학습·평가. **randomTrips 원문 수요를 복제하지 않음** |
| 학습량 | 본 설정 에피소드 100회×1200 시뮬레이션초. 원문의 100,000 decision step과 동일하지 않음. 실제 결정·업데이트 수도 기록 |
| 탐색 | 동일 선형 epsilon 1→0.02, 50,000 결정 동안 감소. 원문 0.99 곱셈 감소와 차이 |
| 최적화 | Adam, MSE, gradient norm clip 10. 모든 알고리즘에 동일 |
| 타깃 | 일반 DQN/Dueling에도 표준 target network 사용, 500 gradient update마다 동기화. Double/D3QN만 online 선택·target 평가 분리. 원문의 일반 DQN 설명과 차이 |
| 종료 | 고정 수요 구간+정리 구간 끝을 유한 에피소드 종료로 처리. 잔여를 기록하고 종료 부트스트랩은 0 |
| 시간 할인 | 유지 1초, 전환 최대4초. 초당 보상을 `Σ gamma^k r_k`로 합치고 bootstrap도 `gamma^elapsed` 사용. 전환이 긴 것을 동일 1초로 오인하지 않음 |

본 설정 저·중·고는 450/1500/3000 veh/h 합계다. 실제 포화율에 대한 보편적 기준이 아니라 이 네트워크의 사전 지정 수요 단계다. 고정 신호·대기열 기준선의 실측 대기열과 완료율로 단계 차이를 확인한다. 도로 길이·회전 비율·차량 특성을 바꾼 경우 다시 검증해야 한다.

## 여섯 보상: 코드의 정확한 정의

원문은 보상의 이름·목표를 설명하지만 6개 모두의 완전한 실행 식·정규화·측정 창을 제공하지 않는다. 아래는 이를 바탕으로 정한 **이번 구현의 초당 식**이다. 원문의 수치 결과와 직접 비교하지 않는다.

각 초 `H`=속도<0.1m/s 차량 수, `N`=네트워크 내 차량 수, `vbar`=그 차량 평균속도, `vmax`=13.89m/s, `A`=해당 초 경로를 완료한 대수, `D`=해당 초 실제 진입 대수.

| 이름 | 초당 보상 | 측정 의미 |
|---|---|---|
| WTMin | `-H` | 추가 정지 차량·초 최소화. 누적 대기 합의 차분으로 바꾸지 않음 |
| ASMax | `vbar/vmax`, 빈 네트워크는 0 | 전체 차량 평균속도 최대화. 초기 차량별 speedFactor 때문에 실제 평균이 1을 넘을 수도 있으며 clipping하지 않음 |
| TTMin | `-N` | 추가 네트워크 체류 차량·초 최소화. 완료 차량만 골라 통행시간 계산하지 않음 |
| CTMax | `A` | 네트워크 전체 경로 완료 대수 최대화. 교차로 정지선 통과와 구분 |
| WCTMax | `Σ(완료 차량 허용 최단경로 길이/750m)` | 경로 길이를 고려한 완료 대수. 이 네트워크에서 경로는 유입+유출 edge 길이의 명시적 합, 내부 교차로 연결 길이는 제외한 계획 길이 사용 |
| TMQMax | `D-H` | 원문이 설명한 **실제 진입 대수−정지 대수**. 완료 대수−대기열로 임의 해석하지 않음 |

모든 보상은 황색의 초들도 동일하게 누적한다. 별도의 전환 벌점을 추가하지 않았다. ASMax·TMQMax의 빈번한 전환 등 부작용은 지표로 관찰하며, 연구 전에 안전 규칙으로 결과를 바꾸지 않는다.

## 공통 평가

- 평균 관측 대기 = 모든 현재·완료 차량에서 관측한 정지 차량·초 / 예정 차량 수.
- 보정 대기 = (관측 정지 차량·초 + 삽입 불가 미진입 차량·초) / 예정 차량 수.
- 미진입은 아직 출발 예정 시각이 안 된 차량을 포함하지 않음. SUMO의 정수 tick 출발 양자화 1초 자체를 혼잡 대기로 더하지 않음.
- 완료율 = 도착 / 예정. 도착·진입·잔여·미진입과 함께 보관. `예정=도착+잔여+미진입` 수 보존 검사.
- 평균/최대 대기열, 차량별 최대 **관측 누적 정지시간**, 방향별 정지 차량·초, 총 CO2(g), 신호 전환 횟수.
- CO2는 SUMO 기본 차량 배출 모형의 시뮬레이션 값이며 측정 배출량이 아님.
- teleport를 끄고 충돌/teleport 발생 시 해당 실행을 유효 결과로 저장하지 않음.
- 차량별 관측은 끝까지 통과하지 못한 차량도 포함한다. 종료 후의 미래 대기를 추정한 값은 아님.
- 결과표 표준편차는 평가 차량 시드를 먼저 모델별로 평균한 후 독립 학습 시드 사이에서 계산. 차량 시드 5개를 독립 학습 모델 5개로 간주하지 않음.

학습 시드 11/22/33과 평가 차량 시드 1001~1005는 다른 역할이다. 훈련 차량은 `100000+학습시드×10000+episode_index`로 생성하므로 평가 파일과 분리된다. 같은 학습 시드·혼잡도의 모델들은 보상/알고리즘이 달라도 같은 에피소드별 차량 파일을 사용한다.

## 연구 해석

동일 혼잡도 학습→동일 혼잡도 평가가 본 실험이다. 중교통량 학습 모델→저·고교통량 평가 등 일반화는 CLI에서 별도 수행 가능하다. 같은 결과표에서 훈련 혼잡도를 생략하지 않는다.

여섯 보상의 크기와 의미가 다르므로 학습 return으로 보상 간 순위를 정하지 않는다. 평균 대기 하나만 낮고 완료율이 낮거나 미진입이 많으면 좋은 모델로 해석하지 않는다. 파일럿 6에피소드·학습시드1개는 실행 확인용이며 알고리즘 우위의 근거가 아니다.
